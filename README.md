# Futebol Carreira

Simulador de carreira de jogador de futebol, com foco em imersão nos campeonatos regionais e estaduais brasileiros. Mecânicas inspiradas em Copero (XP por desempenho), Brasfoot (gestão/mercado) e Pro Clubs (arquétipos e perks).

Design completo em [`docs/game-design.md`](docs/game-design.md).

## Status

Estrutura inicial do projeto (TypeScript, motor + CLI, sem interface gráfica por enquanto). Implementação ainda não iniciada — ver seção 8 do design doc para a ordem das fases.
